1. ¿Qué es el login en una aplicación.
Respuesta: El login es una herramienta la cual permite identificar 
a un usuario antes de darle acceso a ciertas funciones que solo puede tener
el usuario principal.

2. ¿Por qué algunas rutas deben estar protegidas.
Respuesta:Algunas rutas deben estar protegidas porque pueden contener información privada, 
registros internos o acciones que no deberían estar disponibles para cualquier persona.
Un uso indebido de estas podría acarrear vulneraciones para todos aquellas personas
de la comunidad que las utilicen.

3.¿Qué tipo de información no debería exponerse públicamente?
Respuesta: No se debe exponer publicamente aquella información que vulnere o represente
un riesgo para la persona como lo son: contraseñas, documentos de identidad, teléfonos, 
direcciones, tokens, claves de API ni datos sensibles de la comunidad.
